# Changelog

## 0.2.0 — 2026-09-30

Portfolio-strengthening release of the Governed Agent Workflow Demo.

- replaced the earlier minimal routing demo with a structured workflow control plane;
- added provider health, circuit breaking, bounded retries and safe fallback;
- added explicit tool allowlists and workspace containment;
- added action-bound, expiring, one-time human approval;
- added SQLite-backed idempotency and restart/recovery guards;
- added artifact/receipt integrity verification and stale-evidence detection;
- added tamper-evident execution audit and parent/child evidence gates;
- expanded the behavioral suite to 35 tests;
- added reproducible success, fallback and approval demos;
- added capability, threat-model, interview and acceptance documentation.

Scope remains a local engineering portfolio prototype, not an enterprise production AI platform.
